# 02 · 行为契约

本文列出重写中**必须成立**的核心行为。实现方式可变，这些行为不可变。

**编号**：`B-<域><序号>`。域：1 产品 · 2 扩展 · 3 下载 · 4 文件 · 5 Eagle · 6 IDM · 7 视频号 · 8 界面 · 9 发行 · 10 稳定性。

**验证**：`A` 可自动化 · `M` 必须人工 · `A+M` 自动覆盖规则加人工确认真机效果。

| B-302 | 分离音视频默认使用 FFmpeg streamcopy；仅容器或编码不兼容且用户明确选择时才转码 | A |

| B-304 | 页面解析凭据不得转发给**不同主机**的媒体 CDN | A |
| B-305 | 网络错误只能有上限重试；不得无限循环，不得静默切换到第三方服务 | A |
| B-306 | 单个计划的异常不得终止后台处理循环 | A |
| B-307 | 健康探测的并发刷新必须复用同一轮结果（single-flight） | A |
| B-308 | 用户在校验阶段停止后，完成状态不得覆盖取消状态 | A |

| B-316 | 计划实际执行的下载路径由桌面端在执行时确定并记录；调用方声明的类型只是**提示**，与实际不符时最多自动降级**一次**，且实际路径必须对用户可见，不得静默发生 | A |

## 附：本契约不含的内容

以下在简化中**明确不做**，不属于契约：

| 项 | 说明 |
| --- | --- |
| 配对码与令牌体系 | 无登录、无账号 |
| 防同机恶意进程 | 不在威胁范围 |
| 令牌摘要存储与轮换 | 无令牌 |
| 威胁模型与权限矩阵 | 只做输入合法性校验 |
| 数据库迁移链 | 新库 v1，不迁移 |
| 候选持久化到桌面库 | 候选只在内存与扩展内 |
| 跨版本协议兼容 | 扩展与桌面端同版本发布 |
