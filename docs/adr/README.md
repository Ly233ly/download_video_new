## 何时需要新增 ADR

| 触发条件 | 示例 |
| --- | --- |
| 变更已接受的决策 | 从前端框架 Svelte 改为 React |
| 引入新的结构性机制 | 新的进程间通信方式 |
| 改变信任边界 | 重新引入认证机制 |
| 改变进程模型 | 捕获代理改回同进程 |
| 改变持久化策略 | 允许某种秘密落盘 |

## 不需要 ADR

- 实现细节选择（在对应文档的待确认项中记录）
- 遵循既有决策的常规开发
- 缺陷修复
