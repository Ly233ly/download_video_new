# 11 · 验收规格

本文定义验证层次、回归矩阵、性能与稳定性验收，以及人工复验边界。

**契约来源**：[02 · 行为契约](02-BEHAVIOR.md) 的 `B-101 ~ B-1007`、[07 · 扩展](07-EXTENSION.md) 的 `P-101 ~ P-110`、[14 · 站点适配器](14-SITE-ADAPTERS.md) 的 `A-101 ~ A-117`。

## 1. 验证层次

| 类型 | 标记 | 含义 |
| --- | --- | --- |
| 自动化 | **A** | 可在 CI 或本地脚本中完全自动判定 |
| 人工 | **M** | 必须由人在真实环境中确认 |
| 混合 | **A+M** | 自动测试覆盖规则，人工确认真机效果 |

**原则**：任何标记为 **M** 的项目必须列入发布说明，不得以"自动测试通过"代替。

## 3. 性能验收

必须与旧版本做**同场景对比**。

| 编号 | 场景 | 判据 |
| --- | --- | --- |
| PF-A1 | 1000 条任务列表滚动 | 帧率稳定无掉帧，较旧版有明确改善 |
| PF-A2 | 1000 条任务下状态更新 | 单条更新不触发重建 |
| PF-A3 | 空闲常驻 | CPU ≈ 0，内存显著低于旧版 |
| PF-A4 | 冷启动到可交互 | 不劣于旧版 |
| PF-A5 | 捕获期间系统吞吐 | 不因捕获代理导致明显卡顿 |
| PF-A6 | 并发下载时界面响应 | 界面保持可响应 |
| PF-A7 | 扩展候选列表 200 条滚动与更新 | 帧率稳定；状态更新不触发容器重建（对照 T-EXT-15） |

**测量口径**：

| 项 | 要求 |
| --- | --- |
| 进程树 | 必须统计完整进程树，含 WebView2、捕获子进程与媒体工具 |
| 指标 | CPU、内存、句柄数、吞吐、延迟 |
| 分位 | 必须给出 p95 / p99，不只平均值 |
| 时长 | 稳定态测量 ≥ 10 分钟 |
| 记录 | 机器配置、数据规模、对比方法必须写入发布验证文档 |

**基线**：编码前必须先测一次旧版本，作为对比基准（见 [13](13-ROADMAP.md) 阶段 0.5）。
